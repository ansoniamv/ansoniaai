# Brand assets

Two files belong here and are referenced by the landing page:

- `atlas-mark.png`      — the blue "A" logo mark
- `chicago-skyline.jpg` — the hero background photograph

The mark is placed, never modified: no recolour, crop, rotation, drop shadow,
or CSS filter. Minimum 24px tall in the header, with clear space of at least
its own height on all sides.

Until these files are added the landing page still renders correctly — the hero
falls back to the solid navy scrim and the header shows the wordmark alone —
but it is not launch-ready without them.
